🛒 Sistema de Compra y Venta

Sistema web completo para gestión de inventario, ventas, compras y facturación con IVA automático.

Módulos del sistema

🏷️ Marcas

Registro y gestión de marcas. Paso obligatorio antes de crear productos.

📦 Productos

Ficha completa: precio, costo, stock, IVA, categoría, imagen y fecha de caducidad.

👥 Proveedores

Gestión de proveedores vinculados a los productos del inventario.

🧾 Ventas

Emisión de facturas con cálculo automático de IVA, subtotal y total.

🛒 Compras

Registro de compras a proveedores con actualización automática del stock.

🖨️ Impresión

Cada factura puede imprimirse directamente desde el sistema.

🖨️

Impresión de facturas

Desde el detalle de cualquier venta, el botón Imprimir genera la factura lista para entregar al cliente — con datos del cliente, productos, IVA desglosado y total. Sin herramientas externas.

Reglas de negocio y restricciones

⚠️
No se puede registrar un producto sin una marca previa.El campo "Marca" es obligatorio y solo muestra marcas ya creadas. Sin marcas registradas, el producto no puede guardarse.
⚠️
No se puede vender sin productos en el inventario.El formulario de nueva venta requiere al menos un producto. Sin productos registrados, no es posible generar una factura.
⚠️
No se puede crear una compra sin un proveedor registrado.El campo "Proveedor" es requerido. El sistema solo lista proveedores activos.
🧮
IVA y totales se calculan automáticamente.Al agregar un producto, el sistema calcula subtotal, IVA (15%) y total en tiempo real sin intervención manual.
🚫
Las facturas activas pueden anularse pero no eliminarse directamente.El flujo correcto es: ver factura → anular. El botón "Eliminar" requiere confirmación adicional.
📦
El stock se actualiza al registrar compras.Cada compra suma automáticamente las unidades al inventario del producto correspondiente.
