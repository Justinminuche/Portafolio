  • Un modelo de Random Forest predice el consumo de las próximas 6 horas.

Sistema de compra y venta

Inventario, compras, ventas y facturación con IVA automático.

Módulos

MarcasSe registran antes de crear productos.
ProductosPrecio, costo, stock, IVA, categoría, imagen y fecha de caducidad.
ProveedoresVinculados a los productos del inventario.
VentasFacturas con IVA, subtotal y total calculados.
ComprasActualizan el stock automáticamente.
ImpresiónCada factura se imprime desde su detalle, sin herramientas externas.

Orden de registro

  1. Crear marca
  2. Registrar proveedor
  3. Crear producto
  4. Registrar cliente
  5. Emitir factura

Reglas del negocio

  • No se puede registrar un producto sin una marca.El campo Marca es obligatorio y solo muestra marcas ya creadas.
  • No se puede vender sin productos en el inventario.La nueva venta necesita al menos un producto registrado.
  • No se puede crear una compra sin proveedor.El sistema solo lista proveedores activos.
  • El IVA y los totales se calculan solos.Al agregar un producto se actualizan el subtotal, el IVA (15 %) y el total.
  • Las facturas se anulan, no se borran.Para eliminar una factura el sistema pide una confirmación adicional.
